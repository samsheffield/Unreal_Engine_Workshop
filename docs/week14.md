## Level Sequencer
_The Sequencer is Unreal Engine's multi-track editor used for creating and playing back cinematic sequences in real-time. It is the backbone for all linear content creation in Unreal Engine._

Unreal's Documentation can be found [here](https://dev.epicgames.com/community/learning/tutorials/L999/unreal-engine-sequencer).

- Creating a Level Sequencer Asset (Use the prefix `LS_`).
- Adding Actors to the LS timeline and manipulipating their properties.
- Adjusting animation curves.
- Incorporating Animation Sequences (Skeletal Meshes).
- Connecting playback to an Actor Blueprint.

- Create Level Sequence Player
