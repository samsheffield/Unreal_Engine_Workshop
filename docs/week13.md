## Layered Blend Per Bone

Layered Blend Per Bone lets you mix a base animation (for example, running) with a secondary animation that affects only part of the skeleton (for example, waving or aiming).

## Animation Montages

Animation Montages are designed for event-based one-shot actions that need timing, notifies, or interruption control (for example, player actions such as attacks or gestures). Montages are played through Blueprint using Play Montage nodes.


## User Interfaces: Progress Bars

Progress Bars in UMG can visually represent changing gameplay values such as health, stamina, mana, or sprint duration.


## User Interfaces: In-world UI with Widget Components

Widget Components allow you to display UI elements directly in 3D space, such as health bars above NPCs, interaction prompts, or environmental readouts.
